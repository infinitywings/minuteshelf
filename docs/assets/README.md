Prepared October 13, 2026 for MinuteShelf. UI screenshots were refreshed for the 0.1.10 name change.

## Logo and diagram

The README reuses the existing app icon at [design/brand/meeting-archive-app-icon-v1.png](../../design/brand/meeting-archive-app-icon-v1.png). This documentation change does not rename the app bundle or change its signing identity.

[minuteshelf-workflow.svg](minuteshelf-workflow.svg) is an editable vector diagram. Its three levels show recording inputs, independently chosen STT/VLM/LLM modules, and the meeting archive. Provider lists and implementation limits belong in the main README rather than inside the figure.

Regenerate the SVG without external dependencies:

```sh
node tools/render-readme-diagram.mjs
```

`minuteshelf-workflow.webp` is a browser-rendered preview of the SVG at 1440 × 850. Keep it in sync when editing the source diagram. The main README uses the SVG.

Screenshots were framed by scrolling the actual page, without changing UI text or compositing controls. They use fictional names, documents, and meeting content. The synthetic recording has no audio track; the visible audio controls do not constitute an audio test.

## Recreate the demo

On an Apple Silicon Mac with Xcode Command Line Tools and Node.js:

```sh
node tools/seed-readme-demo.mjs --serve
```

This creates a separate data directory at `.build/readme-demo-2026-10-13` and prints a temporary loopback access link. It uses the current backend and web interface with synthetic media generated by `tools/readme-demo-media.swift`. It does not read the installed app's archive or credential store. Capture, permission requests, model execution, export execution, and RKA refresh are blocked in this demo server.

Open **Project Atlas** for the project view, then **Experiment review · Synthetic demo** for the remaining views. In Notes, scroll to Generated notes; in Playback and Files, frame the relevant panels. Leave “Folder & all files” collapsed so machine-specific paths do not appear in published images. Preserve the visible synthetic-demo labels.

After capture, stop the demo process with Ctrl-C in its terminal. If started elsewhere, `.build/readme-demo-2026-10-13/server.json` records its PID and temporary URL; verify the process before stopping it. Do not publish that runtime file, the local access token, or the `.build` data directory.
