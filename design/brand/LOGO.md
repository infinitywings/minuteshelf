# Meeting Archive — Logo concept 01

Date: 2026-10-04

Concept: overlapping note pages with an audio waveform cut into the foreground page. The pages represent preserved meeting knowledge; the waveform represents conversation. The compact, rounded silhouette and olive/sage palette follow the current notes-first interface.

Asset: `meeting-archive-mark-v1.png`, transparent PNG generated using the built-in image_gen tool. This is a raster design concept, not a vector master. The web UI now uses an unchanged copy at `web/brand/meeting-archive-mark.png`. The macOS development icon is documented separately in APP_ICON.md.

Intended palette: foreground #455426; secondary #9AAA78. Colors are prompt targets, not an assertion of exact generated pixel values.

## Initial prompt

Use case: logo-brand.
Asset type: original standalone logo mark for "Meeting Archive", a macOS meeting recording, notes and project archive app.
Primary request: Design a sophisticated, highly memorable, simple geometric symbol connecting conversation with keeping knowledge. The mark should read as two overlapping softly rounded upright note pages, whose shared negative space subtly suggests a compact audio waveform / lowercase m. Make these ideas one unified emblem, not separate icons pasted together. One broad deep olive green foreground form with a small muted sage page offset behind it; elegant natural proportions, rounded outer corners, crisp smooth vector-like contours, substantial strokes and generous open negative space, recognizable at 24px. An attractive quietly distinctive silhouette, calm editorial productivity brand.
Color palette: deep olive #455426 with a restrained sage #9AAA78 accent. Flat solid fills, no gradients.
Composition: one single large centered mark on a square canvas, approximately 65% of the canvas, ample transparent padding. No background tile.
Constraints: actual transparent alpha background. No text, no letters rendered as typography, no wordmark, no mockup, no presentation board, no captions, no tiny line details, no gradients, no 3D, no shadows, no texture, no microphone pictogram, no generic sparkle, no recording red dot. Original design, not a copy of any existing brand. High-quality finished identity mark with clean anti-aliased edges.
