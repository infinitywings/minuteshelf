Records only the selected window. When presenting in Zoom, select the actual shared content window; the original Zoom window may stop providing video.

The selected window will appear here
What happens when sources change?

Window mode follows only that window, including its active browser tab. It does not follow Zoom's shared source. Display mode includes everything visible on the selected display, including other apps and notifications. To change the capture target, stop and select it again. Missing video is reported as a gap; the recorder never switches targets automatically.
